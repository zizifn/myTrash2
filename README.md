# myTrash2

my trash v2

## Stack

- [npm workspaces](https://docs.npmjs.com/cli/using-npm/workspaces) monorepo
- [TanStack Start](https://tanstack.com/start) (React + TanStack Router + Vite)

## Layout

```
.
├── apps/
│   └── web/        # TanStack Start app (@mytrash2/web)
└── packages/       # shared packages (empty for now)
```

## Requirements

- Node.js >= 22

## Getting started

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:3000.

## Scripts

Run from the repo root:

| Script | Description |
| --- | --- |
| `npm run dev` | Start the `web` app in dev mode |
| `npm run build` | Build every workspace |
| `npm run typecheck` | Typecheck every workspace |
| `npm run preview` | Preview the `web` production build |

Workspace-scoped commands use npm's `--workspace` flag, e.g.:

```bash
npm run build --workspace=@mytrash2/web
npm install <pkg> --workspace=@mytrash2/web
```

## Adding a workspace

Create a folder under `apps/` or `packages/` with its own `package.json`,
then run `npm install` from the root. Both globs are already declared in the
root `package.json`.

## Notes

- `apps/web/src/routeTree.gen.ts` is generated by TanStack Start (on `dev`/`build`)
  and is intentionally committed.
- Production builds output to `apps/web/dist` (`dist/client` + `dist/server`).
